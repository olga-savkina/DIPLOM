# E-Commerce Platform — Backend

Серверная часть интернет-магазина товаров для мам и детей. Реализована как модульное REST API на Spring Boot.

Стек технологий

- Java 22 + Spring Boot 4.0.5
- Spring Security — аутентификация, авторизация по ролям (JWT)
- Hibernate 7 / JPA — ORM, автосоздание схемы БД
- MySQL 8 — база данных
- HikariCP — пул соединений
 Функциональность
 Каталог и товары
- Управление категориями и товарами
- Поддержка вариантов товаров: размер, цвет, объём и другие характеристики
- Для категорий «еда» и «косметика» — учёт сроков годности

 Склад (`warehouse`)
- Резервирование товаров при оформлении заказа
- Списание со склада только после оплаты или доставки
- Управление остатками по вариантам товаров

  Заказы (`orders`)
- Оформление заказов доступно только авторизованным пользователям
- Управление статусами заказов

 Авторизация (`auth`)
- Регистрация и вход
- Разграничение доступа по ролям (клиент / администратор)
- Доступ к управлению магазином только для пользователей с соответствующей ролью

 Аналитика (`analytics`)
- Статистика по продажам
- Данные для построения диаграмм на клиентской части

Блог (`blog`)
- Управление статьями / публикациями

 Структура модулей

```
src/main/java/org/diplom_back/modules/
├── analytics/
├── auth/
├── blog/
├── orders/
├── products/
└── warehouse/
```

Основные сущности

| Модуль | Сущности |
|---|---|
| `products` | `Category`, `Product`, `ProductVariant`, `ProductImage`, `Review` |
| `orders` | `Order`, `OrderItem`, `OrderStatus` |
| `warehouse` | складские остатки по вариантам товаров |
| `auth` | пользователи, роли |
| `analytics` | агрегированные данные по продажам |
| `blog` | публикации |

Схема БД генерируется автоматически через Hibernate при первом запуске.

 Запуск

1. Клонировать репозиторий
2. Настроить подключение к MySQL в `application.properties`:
   ```
   spring.datasource.url=jdbc:mysql://localhost:3306/your_db
   spring.datasource.username=your_username
   spring.datasource.password=your_password
   ```
3. Запустить через Maven:
   ```bash
   ./mvnw spring-boot:run
   ```
